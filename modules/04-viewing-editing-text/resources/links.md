## 📖 Official Documentation

### nano Editor
- **nano Manual** - https://www.nano-editor.org/dist/latest/nano.html
  - Complete documentation for the nano text editor
- **nano Cheat Sheet** - https://www.nano-editor.org/dist/latest/cheatsheet.html

### vim Editor
- **Vim Official Documentation** - https://www.vim.org/docs.php
  - Comprehensive vim documentation and user manual
- **Vim Help (built-in)** - Run `:help` within vim
  - Access vim's extensive built-in help system
- **Vimtutor** - Run `vimtutor` in terminal
  - Interactive 30-minute vim tutorial (highly recommended!)

### GNU Core Utilities
- **GNU Coreutils Manual** - https://www.gnu.org/software/coreutils/manual/
  - Official documentation for cat, head, tail, sort, uniq, wc, and more
- **grep Manual** - https://www.gnu.org/software/grep/manual/
  - Complete guide to grep and regular expressions

## 💡 Tips for Learning

1. **Start with nano** - It's the most beginner-friendly editor
2. **Learn basic vim** - You'll encounter it everywhere, so know the basics
3. **Practice grep daily** - It's one of the most useful commands
4. **Use man pages** - `man grep`, `man less`, etc. are always available
5. **Build muscle memory** - Regular practice makes commands automatic
