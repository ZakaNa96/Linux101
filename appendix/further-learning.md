## Certification Paths

### CompTIA Linux+

**Overview**: Vendor-neutral certification covering Linux system administration.

- **Level**: Entry to intermediate
- **Exam Code**: XK0-005
- **Topics Covered**:
  - System management
  - Security
  - Scripting and automation
  - Networking
  - Troubleshooting
- **Website**: [comptia.org/certifications/linux](https://www.comptia.org/certifications/linux)
- **Recommended Experience**: 12+ months of Linux experience

### LPIC-1 (Linux Professional Institute)

**Overview**: The first certification in LPI's multi-level program.

- **Level**: Junior Linux Administrator
- **Exams Required**: 101-500 and 102-500
- **Topics Covered**:
  - System architecture
  - Linux installation and package management
  - GNU and Unix commands
  - Devices, filesystems, and FHS
  - Shells and scripting
  - User interfaces and desktops
  - Administrative tasks
  - Essential system services
  - Networking fundamentals
  - Security
- **Website**: [lpi.org/our-certifications/lpic-1-overview](https://www.lpi.org/our-certifications/lpic-1-overview)

### LFCS (Linux Foundation Certified System Administrator)

**Overview**: Performance-based certification from the Linux Foundation.

- **Level**: System Administrator
- **Format**: Hands-on exam in a live environment
- **Topics Covered**:
  - Essential commands
  - Operation of running systems
  - User and group management
  - Networking
  - Service configuration
  - Storage management
- **Website**: [training.linuxfoundation.org/certification/linux-foundation-certified-sysadmin-lfcs](https://training.linuxfoundation.org/certification/linux-foundation-certified-sysadmin-lfcs/)

### Red Hat Certifications

**Overview**: Vendor-specific certifications for Red Hat Enterprise Linux.

| Certification | Level | Description |
|--------------|-------|-------------|
| RHCSA | Entry | Red Hat Certified System Administrator |
| RHCE | Intermediate | Red Hat Certified Engineer |
| RHCA | Expert | Red Hat Certified Architect |

- **Website**: [redhat.com/en/services/certification](https://www.redhat.com/en/services/certification)
- **Note**: All exams are hands-on, performance-based

## Career Paths in Linux

### System Administrator

**Role**: Manage and maintain Linux servers and infrastructure.

- Entry salary: $50,000 - $70,000
- Skills: User management, networking, security, automation
- Growth: Senior Sysadmin → Infrastructure Manager

### DevOps Engineer

**Role**: Bridge development and operations, automate deployments.

- Entry salary: $70,000 - $100,000
- Skills: CI/CD, containers, cloud, scripting, IaC
- Growth: Senior DevOps → Platform Architect

### Site Reliability Engineer (SRE)

**Role**: Ensure reliability and scalability of services.

- Entry salary: $90,000 - $130,000
- Skills: Programming, monitoring, incident response
- Growth: Senior SRE → Principal SRE

### Cloud Engineer

**Role**: Design and manage cloud infrastructure.

- Entry salary: $70,000 - $100,000
- Skills: AWS/Azure/GCP, networking, security
- Growth: Senior Cloud Engineer → Cloud Architect

### Security Engineer / Analyst

**Role**: Protect systems and data from threats.

- Entry salary: $65,000 - $90,000
- Skills: Security tools, hardening, penetration testing
- Growth: Senior Security → Security Architect / CISO

### Network Engineer

**Role**: Design and maintain network infrastructure.

- Entry salary: $55,000 - $80,000
- Skills: Routing, switching, firewalls, troubleshooting
- Growth: Senior Network → Network Architect

### Embedded Linux Developer

**Role**: Develop software for embedded devices.

- Entry salary: $70,000 - $100,000
- Skills: C/C++, kernel development, hardware interfaces
- Growth: Senior Embedded → Firmware Architect
